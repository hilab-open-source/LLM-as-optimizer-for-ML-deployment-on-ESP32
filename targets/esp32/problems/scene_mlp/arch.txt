Model: scene classifier (ResNet-style int8 MLP), running on the ESP32 CPU.

  Input:     INPUT_SIZE = 1024 int8 values per sample
  Stem:      Dense(128, relu)        W_stem[128][1024], b_stem[128]
  ResBlock1: Dense(128,relu) -> Dense(128) + skip -> relu     (W1a,b1a,W1b,b1b)
  ResBlock2: Dense(128,relu) -> Dense(128) + skip -> relu     (W2a,b2a,W2b,b2b)
  Output:    Dense(20)               W_out[20][128], b_out[20]  (no relu)
  Work:      199,168 int8 multiply-accumulates per sample; 197 KB of weights.

Fixed-point scheme (must be preserved exactly):
  Each dense layer computes acc(int32) = bias + sum(W[int8] * x[int8]), then
  acc >>= 7 (arithmetic shift), then ReLU and clamp to int8 [-128,127]. The output
  head has no ReLU. The residual skip is added AFTER the >>7 requant.
All int8 outputs must be bit-identical to the reference for every one of the
8 test vectors, before and after the timed runs.
